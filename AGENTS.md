# AGENTS.md

## Design Context

This project carries design context for the impeccable design workflow:

- **`PRODUCT.md`** (root): strategic context. Register `brand`, platform `web`. A Shopify storefront for **Blossom Bloom Creations**, selling beautifully designed personalized drinkware to gift buyers. Read it before any UI work for users, positioning, brand personality, anti-references, and design principles.
- **`DESIGN.md`** (root): the visual system. Colors, typography, elevation, and component conventions extracted from the Liquid/Tailwind code. Follow its tokens and Do's/Don'ts to stay on-brand.

When building or changing UI, read both files first and keep new work consistent with them.
